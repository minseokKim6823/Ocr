# This file covers the lightweight dependency stack for running Gemma 4 on a
# CPU-only machine via Ollama.  The model itself is NOT installed via pip —
# Ollama manages the quantized GGUF weights separately.
#
# Before running the package, pull the model with Ollama:
#   ollama pull gemma4:e2b    # ~3 GB — good starting point for most CPUs
#   ollama pull gemma4:e4b    # ~6 GB — higher accuracy if RAM allows
#
# Install: pip install -r requirements-cpu.txt
# ==============================================================================
